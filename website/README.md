# Household Expense — Showcase Website

Marketing site for **Household Expense**: GSAP scroll storytelling, Lenis smooth scroll, and a Three.js / R3F hero.

## Run

```bash
cd website
npm install
npm run dev
```

Open http://localhost:5177

## Build

```bash
npm run build
```

Static output lands in `dist/`. Place the release APK at `public/downloads/latest.apk` before build so the Download CTA works.
